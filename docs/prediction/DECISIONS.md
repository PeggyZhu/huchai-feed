小区级。

挂牌价、评估价、成交价是不同口径，绝不混用。每一条注明口径。

观察池公开展示在 GitHub Pages。展示页接到站点上是路线图里的 M5，不是 M0。

## 阈值

2026-11-28 起，下面两条超额涨幅和「成交少于 3 笔不打分」改由文末「2026-11-28」的套数规则替换。这三行原文保留。连续 8 周无新证据仍然有效。

超额涨幅相对全市完整月锚点计算。

- 超额涨幅 ≥5% 进入「低」。
- 超额涨幅 ≥8% 进入「中」。
- 连续 8 周无新证据，移出观察池。
- 成交少于 3 笔不打分，只标注。

## 档位与分数

2026-11-28 起，下面「有超额涨幅」和「只有超额涨幅」改由文末那一节的套数增速承担。高档、纯征询、硬过滤和排除不改。

档位规则优先。分数只在同一档位内部排序。

- 高：两清或准动迁挂牌，并且贴边地块已有征收决定。
- 中：贴边地块处于冻结或决定，本小区不在清单内，并且有超额涨幅。
- 纯征询不升高。
- 低：只有超额涨幅。

硬过滤：户数>50 且 套均≤70㎡。两条同时成立，才进入可评分的集合。

排除已经处于下列阶段的小区：已冻结、已决定、已签约、已腾退。

分数的上限是：程序 0–50、量价 0–30、结构 0–20。

## 假阳性控制

下列情形要单独认出来，不能当成征收信号：收储、成套改造、市政冻结、学区、对倒。

社交媒体交叉验证权重为 0。

含商业口径与房管局住房口径不相加。

## 2026-11-28：量价只看成交套数

确认日期：2026-11-28。这一节替换上文「阈值」里的超额涨幅，以及「成交少于 3 笔不打分」。不替换程序分、结构分、硬过滤、排除、假阳性、纯征询不升高，也不替换分数上限（程序 0–50、量价 0–30、结构 0–20）。档位规则仍然优先，分数只在同一档位内排序。

量价不再使用挂牌价、评估价、成交价，也不再相对全市锚点计算超额涨幅。只用公开成交的套数。

- 按自然月计数。一个 3 个月窗口同时做两段比较：与上年同一三个月，以及与紧挨在前面的三个月。
- 当前这个 3 个月的套数达到 8，才计算增速。不到 8，标「样本不足」，量价分记 0。8 是当前窗口的门槛，不是比较段的门槛。比较段可以少于 8 套，只要大于 0。
- 两段比较各自都要落在已经采集的月份里，并且比较段的套数大于 0，这一腿才有增速。缺一腿，或比较段为 0，不把没采集到的月份当成 0，也不把 0 当成基期去算增速。量价分仍是 0。
- 两腿都有增速时，取较低的一腿。达到 5% 是低档的量能门槛，达到 8% 是中档的量能门槛。5% 和 8% 沿用 2026-11-25，比较的对象从价格超额改为套数增速。比较用精确分数，不先四舍五入。
- 量价分：较低增速达到 8% 记 30，达到 5% 但不到 8% 记 15，其余记 0。不足样本也是 0。
- 回看公告日之前的 12 个月，逐个月末判断会不会碰到上面的线。同比要用到再往前一年的三个月，那三个月可以早于这 12 个月，只要落在已采集的月份里。公告当日和之后的成交不进入这 12 个月。
- 页面上的档位用最近一个完整月为止的窗口，不用回看里某一次碰到的线去改当天的档。
- 未覆盖的月份不是 0。搜索没有返回记录，也不是 0。名称对不上的结果标待核，不借用别的小区的套数。口径待核的套数可以展示，不据此升档。
- 硬过滤仍然是户数>50 且套均≤70㎡。缺一项就是未知，不排档。所以量能线出现过，档位仍可能是未分档。
- 中档仍要贴边地块处于冻结或决定，且本小区不在清单内，再加上较低增速达到 8%。低档是只有套数增速达到 5%，没有更高的程序档。高档仍只来自两清或准动迁挂牌并且贴边已有征收决定。
