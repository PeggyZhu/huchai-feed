# 小区级征收预测：已确认决定

确认日期：2026-11-25。下面各项是所有者当天确认的决定。本文只记录决定和路线图，不记录任何小区、价格或成交笔数。

里程碑 M0 只把这些决定落成文档和空表。回填、抓取、计算和页面都不在这一步。

## 粒度

小区级。

## 量价数据

只用免费公开数据：官方公告、署名媒体、公开成交信息。

不使用付费授权数据。禧泰、中指等来源不可公开再分发，因此不进入本仓库。

挂牌价、评估价、成交价是不同口径，绝不混用。每一条注明口径。

## 观察池

观察池公开展示在 GitHub Pages。展示页接到站点上是路线图里的 M5，不是 M0。

## 范围

全上海市。

## 阈值

超额涨幅相对全市完整月锚点计算。

- 超额涨幅 ≥5% 进入「低」。
- 超额涨幅 ≥8% 进入「中」。
- 连续 8 周无新证据，移出观察池。
- 成交少于 3 笔不打分，只标注。

## 档位与分数

档位规则优先。分数只在同一档位内部排序。

- 高：两清或准动迁挂牌，并且贴边地块已有征收决定。
- 中：贴边地块处于冻结或决定，本小区不在清单内，并且有超额涨幅。
- 纯征询不升高。
- 低：只有超额涨幅。

硬过滤：户数>50 且 套均≤70㎡。两条同时成立，才进入可评分的集合。

排除已经处于下列阶段的小区：已冻结、已决定、已签约、已腾退。

分数的上限是：程序 0–50、量价 0–30、结构 0–20。

## 假阳性控制

下列情形要单独认出来，不能当成征收信号：收储、成套改造、市政冻结、学区、对倒。

社交媒体交叉验证权重为 0。

## 网签大盘锚点

含商业口径与房管局住房口径不相加。

## 旧自动任务

grok.com 上的旧自动任务「沪拆信号周更」和「沪拆信号发布校验」，在新版上线之前并行运行。新版上线之后，由所有者手动停用。

## 路线图

- **M0**：决定和脚手架。即本文、表结构、空表和校验。不填数据，不抓取，不打分。
- **M1**：证据台账回填。
- **M2**：官方公告增量抓取，并做小区匹配。匹配只使用四类结果：程序内、部分覆盖、贴边、待核。

- **M4**：规则引擎与回测。
- **M5**：HTML 周报和 JSON 产出。这一步接在现有周一流程之后，不替换周一的网签录入。
